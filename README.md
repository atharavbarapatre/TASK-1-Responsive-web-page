# BrandLogo - Modern Digital Agency Landing Page

A fully responsive, modern landing page template designed for digital agencies, web development firms, or creative portfolios. This project was built using HTML5, CSS3, and Vanilla JavaScript, focusing on clean design, smooth animations, and a seamless user experience across all devices.

## 🚀 Features

- **Responsive Design**: Adapts perfectly to desktops, tablets, and mobile devices using CSS Grid and Flexbox.
- **Modern UI/UX**: Includes a hero section with a gradient background, high-quality images, and smooth hover transitions.
- **Dynamic Navigation**: A sticky navigation bar that changes its background on scroll, complete with an active scroll-spy to highlight the current section.
- **Mobile Menu**: A fully functional hamburger menu for seamless navigation on smaller screens.
- **Animated Statistics**: Dynamic number counters that animate when they scroll into the viewport, using the `IntersectionObserver` API.
- **Well-Structured Sections**: Includes sections for About Us, Services, Portfolio, Testimonials, Team, and a Contact form.
- **Easily Customizable**: Built with CSS variables for quick theme and color changes.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better accessibility and SEO.
- **CSS3**: Custom styling, animations, Flexbox, and CSS Grid. 
- **JavaScript (ES6+)**: DOM manipulation, event listeners, and Intersection Observer API for scroll animations.
- **Google Fonts**: Uses the 'Inter' font family for crisp and clean typography.
- **SVG Icons**: Lightweight and scalable vector graphics for the services section.

## 📂 Project Structure


## 💻 Getting Started

To view or modify this project locally, follow these simple steps:

1. **Clone the repository**:
   ```bash
   git clone <your-repository-url>
   ```
2. **Navigate to the project directory**:
   ```bash
   cd task-1
   ```
3. **Open the project**:
   Simply double-click the `index.html` file to open it in your default web browser, or use a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for a better development experience.

## 🎨 Customization

You can easily change the color scheme by modifying the CSS variables located at the top of the `style.css` file:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --text-color: #333333;
    --bg-color: #ffffff;
    /* ... */
}
```
